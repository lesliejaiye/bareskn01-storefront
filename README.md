# Bareskn | Shopify E-Commerce Development
Building a modern Shopify storefront for a skincare brand, exploring e-commerce development, Liquid templating, dynamic product data, metafields, metaobjects, and custom theme development. Developed using Shopify CLI, JavaScript, and Git.
=======

## Project Overview

Bareskn is a full-stack e-commerce development project focused on building and customizing a modern skincare storefront using Shopify. The project explores Shopify's commerce architecture, Liquid templating, storefront customization, and product data management to create a functional and scalable e-commerce experience.

Through this project, I am applying my software engineering experience to the e-commerce ecosystem, with an emphasis on dynamic content rendering, reusable components, structured product data, and API-driven integrations.

The goal is to demonstrate practical experience working with Shopify's development environment while building a maintainable storefront that reflects real-world e-commerce requirements.

## Key Areas of Development

- **Storefront Customization:** Customizing Shopify themes using Liquid, HTML, CSS, and JavaScript.
- **Data Modeling:** Creating and managing product metafields and metaobjects to structure reusable product information.
- **Dynamic Rendering:** Connecting Shopify product data to storefront components using Liquid.
- **Theme Architecture:** Exploring Shopify's theme structure, sections, snippets, templates, and reusable components.
- **E-Commerce Functionality:** Implementing product information, variants, collections, and dynamic product experiences.
- **Development Workflow:** Using Shopify CLI, Git, and version control to manage development and track changes.
